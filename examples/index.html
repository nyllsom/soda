修改：复制源码后进入目标目录，执行 soda deck.md 生成 deck.html。编译需要 Python 3.12+；完整展示还需要 Typst。

主题也可以自己改。

直接运行 soda theme 查看中文写法；说明和配置生成都可离线使用，无需 Python。

soda theme init
soda deck.md --theme theme.json

在稿件目录生成 theme.json，改好后编译。默认继承 NJU；要从 IPADS 开始，生成时加 --from ipads。已有文件不会被覆盖。

{
  "extends": "nju",
  "name": "我的主题",
  "primary": "#245a73",
  "accent": "#a65432"
}

primary 是主色，accent 是辅助强调色。只写要修改的字段；其余样式和标识继承原主题。

主题路径相对 Markdown；自己的标识图片路径相对主题 JSON。换标识、字体和更多字段，运行 soda theme --reference 查看。
